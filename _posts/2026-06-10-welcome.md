## How this works

Every post lives in the `_posts/` folder as a Markdown file named:

```
YYYY-MM-DD-some-title.md
```

The front matter at the top of this file (between the `---` lines) controls
the title, date, and tags. Everything below it is written in normal Markdown.

## Markdown basics

- **Bold** and *italic* text
- [Links](https://example.com)
- Lists like this one
- Inline `code` and fenced code blocks:

```python
print("hello, world")
```
